# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, and keep discussion about the work.
Harassment, personal attacks, and discriminatory language aren't tolerated.

Report unacceptable behavior privately to the maintainer through a
[GitHub security advisory](https://github.com/Gthejesraj/driftfix/security/advisories/new)
(it's the only private channel on the repo). Reports are kept confidential.
Maintainers may remove comments, close issues, or block contributors who
violate this code.
